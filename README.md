Project Title and Purpose

- The working project title is ThreadCraft Studio (or ThreadCraft).   
- It is a browser-based interactive web application and web-based apparel customization system.   
- Its purpose is to help online shoppers personalize a shirt or hoodie design and see how it will actually look in real time before deciding whether to purchase or save it. 
- It aims to give users an accessible, beginner-friendly way to experiment with colors, text, and design ideas without requiring prior design software experience.   
- Its goal is to let users visualize and save a personalized garment design (excluding checkout, payment, shipping, tax calculation, and financing).   

Intended Audience

- The primary audience consists of everyday online shoppers and fashion lovers who enjoy customizing their own clothes, including teens, students, and Gen Z users.
- Users are expected to have familiarity with e-commerce shopping apps (such as Shopee, Lazada, or Instagram shops) and basic knowledge of handling image files (such as JPG or PNG) when uploading their own designs.   
- It supports both desktop/laptop computers and mobile phones or tablets running modern web browsers (such as Chrome, Safari, Firefox, or Edge) with JavaScript enabled.   
- It is designed to be accessible anywhere—at home, in a dorm, or while commuting—over normal to fast broadband or mobile data connections.   
- It also considers users with visual impairments (through clear fonts and high-contrast colors) as well as the project team (developers and testers) working with the SRS and test cases.   

Primary Task

- Register an account and log in using an email address and password (and log out).   
- Select a garment type (Hoodie or T-Shirt) and browse or filter available products before customizing.   
- Customize a garment by choosing a size and fabric color, adding custom text (up to 30 characters with position options like Center, Top, or Bottom), selecting from preset graphics or uploading a picture, and creating freehand drawings or artwork.
- View a live, real-time 2D/3D preview of the design and rotate or inspect it 360∘
- Save finished customized designs and access or retrieve them again in the user's account or dashboard.

How to Run the Prototype

- Open the project folder in your code editor (such as Visual Studio Code).
- Make sure all local files—including index.html, customer.html, index.js, css/style.css, 3D model files (.glb), and image/graphic assets—remain in their proper folders.
- Open index.html (or customer.html) in a modern web browser with JavaScript enabled (such as Chrome, Firefox, Safari, or Edge), or serve the folder using a simple static local server.
- Select a garment (Classic T-Shirt or Pullover Hoodie), customize the size, fabric color, custom text, graphics, or freehand drawing with real-time preview updates, and save or view your designs.
